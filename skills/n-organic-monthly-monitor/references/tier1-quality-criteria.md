# Tier 1 品質基準

このドキュメントは、生成するレポートが Tier 1 コンサルファーム（McKinsey / BCG / Bain）水準の納品物として通用するかを判定するためのチェックリストである。

## 自己評価マトリクス（8軸）

レポート完成後、以下8軸で自己評価する。各軸 A / B / C / D の4段階。最終納品の前に少なくとも6軸でB+以上を確保すること。

| 評価軸 | A水準（Tier 1） | C水準（Tier 2以下） |
|---|---|---|
| ① 問いの鋭さ | 「市場の構造変化」の先にある「N organic固有の経営課題」に切り込めている | 「市場の構造変化」止まり |
| ② 分析の深さ | 独自の構造分析がある | 既存業界レポートの引用に頼っている |
| ③ ファクトベース | 出典明示、定量データの粒度・鮮度が揃っている | 数値があっても出典が曖昧、鮮度バラつき |
| ④ 戦略的洞察 | 逆張り的・反直感的な示唆がある | 当たり障りない結論 |
| ⑤ アクション具体性 | 意思決定対象に「YES/NO/条件付きNO」で踏み込める | 「論点提示」止まり |
| ⑥ 構造・論理性 | 章立ての論理連結が強い | セクション間の橋渡し不足 |
| ⑦ 客観性 | 公開情報のみ、内部数値は別軌道 | 内部数値混在で「客観レポート」を名乗っている |
| ⑧ ビジュアル品質 | チャート・図解で「読む前にわかる」 | 表中心、図解ゼロ |

## Tier 1 と Tier 2 を分ける7つの致命的弱点

過去の自己評価から抽出された、Tier 2に落ちる典型パターン。それぞれに対する処方箋を以下に示す。

### 弱点① 「So what?」が弱い

**症状：** 市場データを並べるだけで、N organic固有の戦略的解釈が薄い。

**処方：** 各市場トレンドに対して必ず以下の3点を書く：
- 事実：データそのもの（出典付き）
- 解釈：N organicに対する意味
- 示唆：意思決定に繋がる方向性

たとえば「ダーマコスメは2026年が業界全体の主戦場化」で終わらせず、「ダーマコスメの主戦場化は、N organicにとって機会ではなく罠である可能性が高い。理由は3つ —」と踏み込む。

### 弱点② 競合分析が「ブランド名の羅列」止まり

**症状：** 競合4象限マッピングを描いただけで、5年前のコンサル提案と同じレベル。

**処方：** Tier 1は以下のような定量分析を含める：
- 競合の売上推移、SNS言及量、新規獲得CPAの推定
- N organicとの顧客重複度の定量推定（パネルデータからの推測でも可）
- 「N organicの顧客が次に流出する先」の仮説と検証方法
- 「観察」ではなく「分析」として書く

### 弱点③ Sミルク（または主力新製品）評価の「逃げ」

**症状：** 「リブランディング体現の第一弾と位置付けられる」「市場反応は今後検証」という安全な表現。クライアントに媚びる構造。

**処方：** 3つの戦略的リスクを明示的に書く。例：
- 「ロイヤル顧客の感情と乖離する可能性」
- 「機能訴求でL'Oréal系・資生堂系との直接比較に晒される」
- 「『成分比較ゲーム』の土俵に乗ることを意味する」

クライアントが嫌がる指摘を書けないなら、コンサルファームを名乗る価値がない。

### 弱点④ 「整合度評価表」の根拠が示されていない

**症状：** 「高 / 中 / 低」のスコアを付けたが、評価ロジックが不在。

**処方：** 各項目について「以下の3つの条件を満たす場合に『高』とする」というルーブリックを明示する。ないと印象論に見える。

### 弱点⑤ 月次「論点」が前号と同じ

**症状：** 毎月同じ論点を繰り返すレポート。クライアントから「何を見ているのか」と疑問を持たれる。

**処方：** 月次レポートとして「前号から何が変わったから、論点の優先順位/中身がこう変わるべき」という更新を必ず入れる。リスクマトリクスに「前号→本号」の変化欄を入れるのは必須。

### 弱点⑥ 数値の粒度・鮮度のばらつき

**症状：** 2024年データ、2025年見込、2019-2023年データ等が混在。「2026年5月時点のモニタリング」を名乗る資格なし。

**処方：** 月次レポートには必ず直近のシグナルを含める：
- @cosmeの最新ランキング
- Googleトレンド推移
- 直近のSNS言及量
- 業界誌の最新号（前2-3ヶ月以内）

### 弱点⑦ ビジュアル・図解の完全欠如

**症状：** 表は10個あるが、チャート・ダイアグラム・図解が1枚もない。

**処方：** 最低でも以下3点のチャートを含める：
- 市場規模推移のタイムシリーズチャート
- 競合ポジショニングマップ（散布図）
- 戦略フレームワーク（時間軸 / 選択肢の構造化）

## レポートに必ず含めるべき5つの構造要素

以下のいずれかが欠けていたら、それはTier 1レポートではない。

### 要素A：Our Thesis（中核仮説）

コンサルファームとしての賭けを1文で書く。検証可能でなければならない。例：

> 「N organicの戦略的勝ち筋は、ダーマコスメ勝者になることではなく、ポストダーマコスメ時代の自然回帰需要を独占する位置取りである。Sミルクは戦術として正解だが、ブランド資産投資は別軌道で進めるべきだ。」

このThesisが、レポート全体の骨格を定める。

### 要素B：3つの不都合な事実

エグゼクティブサマリーの冒頭に置く。各事実には以下3点が紐づく：
- 定量データ（具体的な数値）
- 公開ソース（出典明示）
- N organicへの意味（So what?）

例：
- 「自然派・オーガニック市場 +3.1% → 4セグメント中で最も低い成長率」
- 「Anua日本売上100億円突破・前年比3倍以上 → N organic推定規模と同等の直接競合化」
- 「Sミルクの@cosme評価4.9点 → リブランディング旗艦としては低水準」

### 要素C：3つの意思決定論点（Pro/Con + 推奨）

経営判断対象を3つに絞る（4つ以上は意思決定対象として多すぎる）。各論点には：
- Pro / Con表（4-5項目ずつ、対称的に列挙）
- 我々の推奨：「YES」「NO」「条件付きNO/YES」を明示
- 根拠：3つの理由を箇条書きで

「論点提示」止まりはTier 2。意思決定に踏み込む踏み込まないかが分水嶺。

### 要素D：5つの Uncomfortable Truths

クライアントが見ようとしない事実の指摘。独立章として配置する。例：
- 「『ありのまま』と『闘う』のブランド緊張」
- 「@cosme評価が業界トップ水準（5.5+）に未到達」
- 「シロク事業のCA内部での構造的優先度」
- 「N organicのラグジュアリー化上限」
- 「Anuaの学習速度に勝てない構造」

これらの「直面すべき事実」がないレポートは、クライアントに媚びる構造になっている。

### 要素E：検証可能な先行指標

Our Thesis は賭けである以上、検証可能でなければならない。3つの先行指標A/B/Cを示す：
- 何を測るか（指標）
- どこから取るか（データソース）
- 何が見えたらシグナルか（解釈）
- いつ計測するか（サイクル）

## 経営会議でこのレポートを配布した場合の理想反応

理想：「Our Thesisに賛成/反対」「3つの意思決定の優先順位を議論したい」「Uncomfortable Truthsの3番目について深掘りしたい」

回避すべき：「市場の状況はよく分かった、で、我々は何を決めればいい?」 — これはTier 2フィードバックの典型。コンサルファームのレポートで最も避けるべき反応。
