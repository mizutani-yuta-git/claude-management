## 数値の鮮度判定基準

引用する数値は以下の鮮度を満たすこと：

| データ種別 | 許容範囲 |
|---|---|
| 市場規模 | 過去2年以内のデータ |
| 競合売上 | 過去1年以内、できれば最新四半期 |
| 消費者調査 | 過去6ヶ月以内 |
| @cosme評価点 | 月次更新中の最新値 |
| 業界誌引用 | 過去3ヶ月以内の号 |

これより古いデータを使う場合は、出典欄に必ず時点を明示する（例：「2024年度・矢野経済」）。

## 信頼性ランキング

引用ソースの信頼性は以下のように扱う：

### Tier A（一次情報・公式）
- 業界調査会社の有料レポート（矢野、富士、IMARC、TBRC）
- 企業の公式IR、プレスリリース
- 政府統計（MFDS、化粧品工業会）

### Tier B（業界専門メディア）
- 週刊粧業、WWDJAPAN、化粧品ねっと
- @cosme トレンド予測（編集部分析）

### Tier C（参考レベル）
- ニュースサイト記事
- 個人ブログ、Note記事
- Twitterの業界アカウント発言

**Tier Cは「参考」に留め、引用する場合は出典を慎重に書く**（個人推計や独立推計と明記）。

## 出典明記のフォーマット

レポート内では以下の形式で出典を書く：

- 「自然派・オーガニック市場 +3.1%（出典：矢野経済研究所 2024年度）」
- 「Anua日本売上100億円突破（出典：週刊粧業 2025年3月24日発行）」
- 「@cosmeクチコミ評価 4.9点（@cosme N organic ブランドページ、2026年5月時点）」

「業界推計」「複数業界コメントの統合」を使う場合は、複数ソースを参照していることを明示する。

## 内部データの扱い

クライアントから内部KPI（CPA、検索数、社内売上等）が共有されている場合でも、本レポートには含めない。本レポートは**戦略コンサルファームとしての客観性を担保するため、公開情報のみで構成する**。

内部データの統合分析が必要な場合は、本レポートとは別軌道で「内部実績との突き合わせ評価」を実施する。これにより、本レポートは外部配布や経営会議用途に流用可能な柔軟性を保つ。
